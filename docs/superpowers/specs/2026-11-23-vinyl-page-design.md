# Vinyl — страница плеера внутри Spotify (Spicetify)

Дата: 2026-11-23

## Зачем

Хочется красивый экран «сейчас играет», похожий на присланный скриншот
(винил с обложкой, тонарм, крупное название, текст песни в такт, размытый фон
в цветах обложки). Слушает в Spotify на этом же компьютере.

## Подходы

1. **Своё веб-приложение поверх Spotify (Web API).** Работает на любом
   устройстве, но управление только с Premium, нужна регистрация приложения
   у Spotify (жёсткие лимиты), задержка ~1 с, тексты только из LRCLIB.
2. **Spicetify custom app — ВЫБРАН.** Страница внутри самого Spotify: без
   Premium и регистрации, мгновенные события плеера, тексты из самого Spotify.
   Минусы: только десктоп, после обновлений Spotify нужно `spicetify apply`.
3. Тема Spicetify (только CSS) — не даёт винил/тексты, отброшено.

Стек внутри подхода 2: чистый TypeScript без фреймворка (выбор пользователя
ради оптимизации). React из Spotify используется только как тонкая обёртка,
которую требует Spicetify (`render()` должен вернуть React-элемент).

## Цели (первая версия)

- Пункт «Vinyl» в боковом меню Spotify, открывает страницу.
- Пластинка с обложкой текущего трека, крутится при воспроизведении,
  стоит на паузе. Тонарм опускается при play, поднимается на pause.
- Исполнитель (мелко, капсом) и название (крупно).
- Синхронный текст: текущая строка яркая, следующая бледная.
  Нет синхронного → показываем строки без подсветки. Нет текста → надпись
  «Текст недоступен».
- Полоса прогресса с текущим временем и длительностью, клик — перемотка.
- Кнопки: очередь (открывает встроенную очередь Spotify), назад,
  пауза/воспроизведение, вперёд.
- «Up next»: следующий трек из очереди.
- Фон: мягкий градиент из 2–3 цветов обложки, плавно меняется при смене трека.

## Не цели

- Поиск, Discover, Last.fm-бейдж, кнопка «поделиться» — не в первой версии.
- Своё воспроизведение, мобильные устройства.

## Анти-цели (провал, даже если работает)

- Spotify заметно тормозит или греет процессор, пока страница открыта.
- Что-то продолжает работать, когда страница закрыта.

## Решения по производительности

- Вращение пластинки и движение тонарма — только CSS (`transform`,
  `animation-play-state`), без JS на каждом кадре.
- Фон — градиент из цветов `Spicetify.colorExtractor`, без `filter: blur`
  по большой картинке.
- Текст: на событии прогресса ищем текущую строку бинарным поиском,
  DOM трогаем только при смене строки. Прогресс-бар — `transform: scaleX`.
- При закрытии страницы снимаем все слушатели и таймеры.

## Технические детали

- Данные плеера: `Spicetify.Player.data.item` (uri, metadata: title,
  artist_name, image_xlarge_url, duration), события `songchange`,
  `onplaypause`, `onprogress`; управление `togglePlay/next/back/seek(ms)`,
  `getProgress()`, `isPlaying()`.
- Очередь: `Spicetify.Queue.nextTracks[0]`.
- Тексты: `Spicetify.CosmosAsync.get("https://spclient.wg.spotify.com/color-lyrics/v2/track/<id>?format=json&vocalRemoval=false&market=from_token")`,
  поля `lyrics.syncType` (`LINE_SYNCED`/`UNSYNCED`) и `lyrics.lines[]`
  (`startTimeMs` строкой, `words`). Ошибка/404 → «Текст недоступен».
- Сборка: esbuild → один `index.js` (IIFE + глобальная `function render()`),
  CSS встраивается в JS и добавляется `<style>` при монтировании.
- Установка: скрипт копирует `index.js` и `manifest.json` в
  `%APPDATA%\spicetify\CustomApps\vinyl`, затем
  `spicetify config custom_apps vinyl` и `spicetify apply`.
- Тесты: чистая логика (поиск строки, разбор ответа текстов, формат
  времени) — `node --test`. UI проверяется вручную в Spotify.

## Решения строителя (мои)

- Шрифт — тот, что уже есть в Spotify; размеры и отступы на моё усмотрение,
  ориентир — скриншот.
- Обложки нет → серая пластинка; трек без uri (локальный файл) → без текста
  и с цветами по умолчанию.
